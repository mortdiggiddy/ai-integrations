## Reading the map

`[X]` means DONE, `[~]` means IN PROGRESS, `[ ]` means OPEN, and `[S]` means SUPERSEDED. A `requires` line lists the exact recorded `Blocked by` IDs, including completed and superseded prerequisites. It is not a list of only unresolved blockers. `none` means no recorded blocker, not execution authorization.

An active ticket normally starts after retained prerequisites are DONE. Superseded prerequisites are satisfied only by their recorded scope disposition. The limited offline construction exception for DSR-1.1 and DSR-1.2 remains as recorded in the README; it does not authorize live calls or later phases.
