# Inspectable supporting evidence

These immutable captured records support maintained planning. They do not create another specification, backlog or decision authority. The [canonical documents](../../../../canonical-documents.md), [maintained tickets](../../../../tickets/README.md) and [conditional proposal](../README.md) retain their existing ownership and qualification boundaries.

Each JSON projection contains the original SHA-256, captured content, declared privacy transformations and limitations. The [preservation manifest](../preservation-manifest.json) separately binds the exported bytes. Sanitization generalizes operator and contributor attribution, local paths and workspace identifiers; it maps the historical ticket prefix to DSR. Source URLs, revisions, comment identifiers and technical dispositions remain available. Embedded historical paths describe captured context and are not maintained repository links. These projections cannot replace byte-identical native transcripts, runtime checkpoints or original recovery inputs.
