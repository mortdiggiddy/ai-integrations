Subscription organization usage controls are in claude.ai; generic Console API billing advice does not establish billing for this subscription invocation.

The public documentation differs in scope: the general Code cost/limit descriptions discuss allowances, while the dedicated Enterprise billing article explicitly distinguishes current and legacy plans. Neither generalization verifies which plan this account actually has. Login method and model access alone cannot settle entitlement or billing.

## Monitor disposition and offline evidence

Keep source SHA256 `44754903f656b8c9dd3169a931314f84e8143988fd0473a93c2ab2d01811999e` unchanged. It intentionally requires both flags explicitly false and a non-overage designation before setting `overage_clear_seen`. Treating omission as false would discard uncertainty and cannot be justified as no-billing proof.
