Recovery supplies only an already recorded result to the original pending main call before transport starts. Proving that accepted defer checkpoints expose that pending call to the experimental SDK is a required feasibility test; the MCP fixture does not establish it. If the seam cannot preserve this boundary, stop for an explicit execution placement redesign before model execution rather than silently run native effects inside the engine.
